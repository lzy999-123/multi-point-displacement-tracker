# 多检测点特征跟踪与三态监测系统（ESP32 三视角无线图传）

> 本项目为三视角固定机位无线视觉监测系统：**无需下位机/云台**。3 台 ESP32-CAM 固定架设，从 3 个角度拍摄同一目标，经 Wi-Fi UDP 无线上传画面至 Qt/OpenCV/ONNX 上位机；上位机框选目标后立即自动锁定并三路联动跟踪，持续实时输出目标的**是否移动过、变大或变小、是否倾斜/倾倒**三维状态与事件日志。

---

## 1. 纯无线图传链路

- 上位机 `DisplacementTracker.exe` 画面数据**仅来自 ESP32-CAM 无线 UDP（VID1 协议，端口 `5006`）**，不包含本地摄像头（`VideoCapture` / `QCamera`）或 USB 串口视频解码路径。
- USB 线仅用于给 3 块 ESP32-CAM 供电、烧录固件以及可选的 115200 波特率文本诊断日志读取；使用独立 5V / 充电宝供电时画面传输完全走 Wi-Fi。
- 严格按 ESP32 固件内置 `DEVICE_ID`（1～3）与 `UdpFrameReceiver` 逐包 `id` 校验绑定画面框 1～3，不依赖 USB COM 口顺序。

---

## 2. 快速使用流程

1. 打开手机热点 `Redmi K70E`（2.4 GHz），将电脑连入该热点，确认 3 台 ESP32-CAM 通电并自动联网。
2. 双击 [`host/run.cmd`](host/run.cmd)（增量构建并启动）或直接运行 `host/build/run/DisplacementTracker.exe`。
3. 等待三路画面显示：工具栏支持同步切换 **320×240 / 640×480（默认）/ 800×600** 原生分辨率，以及实时调节硬件 **JPEG 质量（锁定 30 / 24 / 20 / 16 或自动 18～42，默认锁定 `q=30`）**。
4. **框选目标即开始跟踪**：
   - 在任意一路画面中**按住鼠标左键拖拽框选目标**，立即锁定该路并以当前位置/尺寸/姿态自动建立初始参考基准。
   - 勾选工具栏**“三路联动锁定”**时，其余两路自动在全图语义匹配并经连续帧验证后同步锁定同一目标。
   - 右键点击单路画面或点击单路“清除”可清除该路目标；点击看板标签栏右侧**“清除全部”**可一键清空三路目标。
5. **实时三态输出与监控看板**：
   - **移动状态**：`未移动` / `正在移动` / `已移动`（显示方向与像素位移）/ `目标丢失`，内置 360 ms 窗口速度、死区门限与固定机位像素变化门控，有效抑制静止状态下跟踪框微抖导致的误报。
   - **尺寸状态**：`尺寸正常` / `变大 +X%` / `变小 -X%`，采用非对称平滑与形变死区滤波，避免局部抖动导致锁定框反复缩放。
   - **姿态状态**：`姿态正常` / `倾斜 X°` / `已倾倒 X°`，支持竖立至水平 90° 倾倒完整追踪与近对称目标主轴屏蔽。
   - 右下角**实时跟踪与监控**面板同步呈现：总览状态横幅、移动/尺寸/姿态三枚状态胶囊、三路状态卡片、`锁定基准 / 状态归零 / 重置基准 / 导出日志 / 清空` 快捷控制与滚动事件日志。
   - 切换至**参数设置**标签页可调整核心报警阈值（倾斜报警门限默认 `12.00°`、倾倒判定门限默认 `35.00°`、尺寸突变门限默认 `15%`、位移偏离门限默认 `15.00 px`）及轨迹显示/画面清晰度增强开关。

## 3. 核心技术特性

### 上位机视觉跟踪与抗干扰
- **多算法协同跟踪**：集成 **YOLO26n（ONNX Runtime）** 语义定位（含 90° 旋转兜底以适配完全倒伏目标）+ **OpenCV CSRT** 帧间跟踪 + **ORB** 关键点丢失重找，兼顾语义防误锁与任意外观细节的连续追踪。
- **稳框与抗静止抖动**：引入旋转不变形状门控、CSRT/YOLO 一致性保护、异常帧 HOLD 保持缓存、跨视角 3 帧确认、中心点/角度死区与移动状态迟滞防抖，彻底解决静止物体“框抖报移动”和旁路背景误锁问题。
- **画质增强**：`VideoWidget` 开启 `SmoothPixmapTransform` 平滑缩放，并支持纯向量化“画面清晰度增强（去灰/轻锐化）”。

### ESP32-CAM 无线图传固件（`adaptive-udp-v26`）
- **硬件成像优化**：针对 OV3660（24 MHz XCLK + PLL 25 / PCLK 10，原生采集约 27.7 fps）优化零延迟硬件 ISP 参数，消除原厂默认发灰雾感。
- **共享热点防拥塞**：内置分档节拍底限、8 槽 PSRAM 缓冲、机位相位错峰（`DEVICE_ID * 12 ms`）、`ENOMEM` AIMD 自适应退让与 `VREQ02` 实时 JPEG 质量切换；在 Redmi K70E 2.4 GHz 热点下三机并发 `640×480` 锁定 `q=30` 稳定 0 零帧秒、0 重连。
