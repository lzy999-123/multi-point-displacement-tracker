# 三视角固定机位藏品异动监测系统（ESP32 无线图传）

> 本项目为课程大作业原型：**无需下位机/云台**。3 台 ESP32-CAM 固定架设，从 3 个角度拍摄同一目标，经 Wi-Fi UDP 无线上传画面至 Qt/OpenCV 上位机；上位机锁定目标并标定基准后，持续监测目标的**变大、变小、移动、倾斜、消失**，输出单视角/多视角分级告警提示、声音提醒、日志记录与自动截图存证。
>
> 历史 STM32 云台方案保留在 `stm32/` 和 `docs/系统设计方案.md`，已不再作为当前主线功能。

---

## 1. 纯无线传图确认

- 上位机 `DisplacementTracker.exe` 画面数据**仅来自 ESP32-CAM 无线 UDP（VID1 协议，端口 5006）**，工程中不包含任何本地摄像头（`VideoCapture` / `QCamera`）或 USB 串口视频解码路径。
- USB 线仅用于给 3 块 ESP32-CAM 供电、烧录固件以及可选的 115200 波特率文本诊断日志读取；即使将 `camera-runtime.ini` 中的 `serialPort` 清空并改用充电宝/独立 5V 供电，画面传输完全走 Wi-Fi。

## 2. 快速使用流程

1. 打开手机热点 `Redmi K70E`（2.4 GHz），将电脑连入该热点，确认 3 台 ESP32-CAM 通电并自动联网。
2. 双击 `host/run.cmd`（增量构建并启动）或直接运行 `host/build/run/DisplacementTracker.exe`。
3. 等待三路画面显示（工具栏可同步切换 **640×480 / 320×240 / 800×600**，默认 **640×480**）。
4. **锁定目标**：在每路实时画面中**按住鼠标左键拖拽框选目标**（支持任意纹理展品），或单击目标轮廓内部。
5. **锁定基准**：看到三路画面均出现绿色目标框后，点击顶部**“一键全机位锁定基准”**（或各路单独点击**“标定”**）。
6. **实时监测与输出提示**：
   - 画面右上角徽章与左上角指标实时显示：位移（含左/右/上/下方向与像素值）、面积变化百分比（变大/变小）、主轴倾角（近圆/近方目标自动屏蔽无意义倾角）与目标可见性。
   - 右下角融合看板按三视角分级输出：
     - **绿色**：三视角均在基准阈值内（藏品正常）；
     - **单视角预警（1/3 路）**：提示疑似单侧遮挡或单视角变化；
     - **多视角确认告警（≥2/3 路）**：红警确认目标移动/变大/变小/倾斜/移走，自动识别“某视角缩放 + 侧视角位移 = 空间移动”，可选触发提示音并自动保存现场截图至 `alerts/`，支持一键**导出日志**。
   - 异常持续 500 ms 确认触发，恢复持续 1000 ms 确认消除；任一路超 1 秒无新帧自动标记“监控不完整”。

## 3. 2026-11-23 最新优化与三路实机实测（v25）

完整实测 JSON、串口日志、窗口截图与分析见 [优化与实测报告](output/v25-museum-20261123/优化与实测报告.md)。

### 核心优化项
- **ESP32-CAM 固件 `adaptive-udp-v25`**：针对三机共享 2.4 GHz 热点引入每档平滑节拍底限（VGA 60 ms / QVGA 40 ms / SVGA 105 ms）+ `ENOMEM` AIMD 自适应退让 + JPEG 质量超标快速收敛（VGA `q=34~62`）+ `chunk=0` 35 ms 零污染早退 + 8 槽 PSRAM 缓存 + 机位相位错峰（`DEVICE_ID * 12 ms`），彻底消除 v24 不限速时的热点队列拥塞雪崩。
- **固定机位编号与纯无线 UI 升级**：
  - 严格按 ESP32 固件内置 `DEVICE_ID`（1～3）与 `UdpFrameReceiver` 逐包 `id` 校验绑定画面框 1～3，完全不依赖 USB COM 口顺序；移除画面下方地址输入框与遮挡视野的黑色 HUD，三路画面统一固定为 `480×360`（4:3），分辨率与实时帧率显示在机位标题栏。
  - `UdpFrameReceiver` 新增分层诊断计数（`complete / overwritten / stale / expired`）；无目标且不显示掩膜时跳过全帧边缘提取，空闲处理降至 `0.0 ms`。
  - 新增**鼠标拖拽框选目标 ROI**（多尺度模板匹配 + 局部 Lab 背景对比轮廓细化 + 倾倒原地兜底分割），覆盖静止、大幅移动（>120 px）、变大、变小、倾斜、移走与恢复全场景；原有单击选轮廓与 HSV 色块模式完整保留。
  - 右下角整合为双标签页（`实时监控` / `参数设置`），提供三视角分级融合横幅、三路状态卡片、一键锁定/重置基准、声音提醒、多视角确认自动截图存证与事件日志导出。
