# 基于视觉的多监测点位移跟踪系统

3 台 ESP32-CAM 各装在一个二维舵机云台上，通过 WiFi 把视频传给上位机。上位机识别目标（当前为色块），
把目标偏移经 WiFi 发回 ESP32-CAM，再由串口转给 STM32，STM32 驱动舵机跟踪目标。上位机同时计算各监测点的位移。

## 目录

| 目录 | 内容 |
| --- | --- |
| `host/` | 上位机（Qt + OpenCV） |
| `esp32cam/` | ESP32-CAM 固件（Arduino） |
| `stm32/` | STM32 固件（HAL） |
| `docs/` | [系统设计方案](docs/系统设计方案.md)、[通信协议](docs/通信协议.md) |
| `tools/` | 标定与数据分析脚本 |
